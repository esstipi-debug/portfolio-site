# Portfolio Site

A static personal portfolio for freelance inventory/supply-chain optimization
work, built to support job search on Upwork. Flagship project: **Kern**
(live at https://linchpin.fly.dev), presented as four case studies.

Kern was called Linchpin until July 2026, and its repository is private. Older
copy in this repo may still use the old name.

## Structure

- `index.html` — home page (hero, about, skills, case-study index, contact)
- `case-studies/*.html` — one page per case study, independently linkable
- `assets/css/style.css` — design tokens + all component styles
- `assets/js/main.js` — nav toggle, dark-mode toggle, scroll-reveal
- `assets/img/` — screenshots of Kern
- `upwork/profile-content.md` — copy-paste content for your Upwork profile

## Status

The placeholders are filled in: name, years, background, education, certification
and the contact links all carry real values. The site is not deployed — GitHub
Pages is off and there is no published URL yet.
